# Molecular GCN–Transformer

A molecular deep learning project exploring molecular representation
learning and alignment using neural network architectures.

## Project Files

- `molecule-alignment.ipynb` — Main implementation notebook
- `Report.pdf` — Detailed project report
- `results_corrected/` — Selected experimental results,
  evaluation summaries, and visualizations

## Experimental Results

The repository includes visualizations of:

- Training losses and learning curves
- Model alignment diagnostics
- Language model perplexity
- Generated molecular structures
- Molecular sequence length distributions

Selected evaluation metrics are provided in JSON format.

## Getting Started

1. Clone this repository.
2. Open `molecule-alignment.ipynb` in Jupyter Notebook or JupyterLab.
3. Install the dependencies required by the notebook.
4. Configure any required local datasets and paths.
5. Run the notebook to reproduce the experiments.

## Notes

Trained model checkpoints and intermediate generated files
are excluded to keep the repository lightweight.

See `Report.pdf` for the full methodology and experimental analysis.
